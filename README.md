## Featured Projects

### proto-tap

Real-time traffic viewers, one per protocol.

Each tap is a proxy daemon that sits between your application and its backend, capturing traffic on the wire and showing it in an interactive client. No changes to your application code.

| Tool                                              | Captures                | Client   |
|---------------------------------------------------|-------------------------|----------|
| [sql-tap](https://github.com/proto-tap/sql-tap)   | PostgreSQL, MySQL, TiDB | TUI, Web |
| [http-tap](https://github.com/proto-tap/http-tap) | HTTP                    | TUI, Web |
| [grpc-tap](https://github.com/proto-tap/grpc-tap) | gRPC                    | TUI      |

### go-kanna

https://go-kanna.github.io/kanna/

| Tool | What it writes |
|---|---|
| [kanna-validate](https://go-kanna.github.io/kanna/validate/) | `Validate` methods from struct tags, with Rails' error codes |
| [kanna-value](https://go-kanna.github.io/kanna/value/) | Value types held to their rule, and enums to their constants |
| [kanna-orm](https://go-kanna.github.io/kanna/orm/) | The implementation of your repository interfaces, and a chainable scope per table |
| [kanna-mapper](https://go-kanna.github.io/kanna/mapper/) | The functions you declare between domain and wire types |
| [kanna-i18n](https://go-kanna.github.io/kanna/i18n/) | Typed message constructors, the translations compiled in |
| [kanna-di](https://go-kanna.github.io/kanna/di/) | The constructor of a container struct, from the functions next to your types |
| [kanna-fixture](https://go-kanna.github.io/kanna/fixture/) | A constructor for every struct, every field filled |
